# Гайд зі збірки ПК

## 1. Загальні відомості

**Назва ресурсу:** «Гайд зі збірки ПК».
**Призначення:** невеликий інформаційний вебресурс, який покроково пояснює, як самостійно зібрати персональний комп'ютер, що потрібно обрати, на що звернути увагу під час підбору комплектуючих і в якому порядку їх встановлювати.

## 2. Цільова аудиторія

- початківці, які вперше збирають ПК самостійно;
- школярі та студенти, які цікавляться апаратним забезпеченням;
- користувачі, які хочуть зрозуміти, з чого складається комп'ютер, перш ніж купувати готову збірку.

## 3. Функціональні вимоги

Ресурс повинен надавати можливість:
- ознайомитися зі складом ПК та призначенням кожного компонента;
- переглянути покрокову інструкцію зі збірки;
- дізнатися про правила сумісності комплектуючих (сокет, тип пам'яті, форм-фактор, потужність блока живлення);
- ознайомитися з типовими помилками початківців;
- зручно переходити між сторінками за допомогою єдиного навігаційного меню;
- переглядати сайт на пристроях з різним розміром екрана.

## 4. Структура сайту

Ресурс є багатосторінковим і складається з чотирьох сторінок:
| Сторінка | Файл | Призначення |
| Головна | `index.html` | Короткий вступ, мета гайда, перелік розділів |
| Комплектуючі | `components.html` | Опис компонентів ПК: процесор, материнська плата, ОЗУ, відеокарта, накопичувачі, блок живлення, корпус, охолодження |
| Збірка | `assembly.html` | Покрокова інструкція зі складання ПК |
| Сумісність і помилки | `compatibility.html` | Правила сумісності комплектуючих, таблиця порівняння, типові помилки |

Усі сторінки мають спільну структуру: `header` з навігацією, `main` з основним вмістом, `footer` з інформацією про автора. Для розмітки використовуються семантичні елементи `header`, `nav`, `main`, `article`, `section`, `aside`, `footer`.

## 5. Вимоги до дизайну

- **Загальний стиль:** мінімалістичний, технічний, без надлишкових декоративних елементів.
- **Кольорова гама:** фон сторінки - #eef0f1; текст та основні лінії - #15191c; другорядний текст - #4a545a; тонкі розділювачі - #b9c0c4; поточний розділ і примітки - #f5c400.
- **Шрифти:** Segoe UI, Roboto, Arial, sans-serif.
- **Оформлення вмісту:** чіткі заголовки, нумеровані списки для кроків, таблиці для порівнянь, зображення з підписами та атрибутом `alt`.
- **Контрастність:** кольори тексту та фону повинні забезпечувати достатній контраст для читабельності.

## 6. Технічні вимоги

- **Технології:** HTML5, CSS3 (без CSS-фреймворків).
- **Адаптивність:** використання `@media`, гнучких одиниць виміру (`%`, `rem`, `vw`) та Flexbox/Grid; коректне відображення на екранах від 320 px завширшки.
- **Браузери:** Opera GX, Microsoft Edge (актуальні версії).
- **Код:** валідний HTML (перевірка через W3C Validator), зовнішній файл стилів `style.css`, єдина кодова структура для всіх сторінок.
- **Доступність:** семантична розмітка, атрибути `alt` для зображень, коректна ієрархія заголовків (перевірка через WAVE).
- **Продуктивність:** оптимізовані зображення (перевірка через PageSpeed Insights).
- **Публікація:** репозиторій на GitHub, розміщення за допомогою GitHub Pages.
- **Ліцензія:** MIT.
